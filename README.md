## 射频连接器知识库工具

本仓库发布的 [源码包 `rfkb-tools-source-verified.zip`](rfkb-tools-source-verified.zip) 提供两项自建工具：

- **`rfkb-review` Skill**：查询本地射频连接器知识，固定记录与证据版本，并对已明确提供的尺寸和公差执行检查。
- **`rf_knowledge` MCP**：以 stdio 方式连接本地知识库，提供检索、记录读取、证据上下文和只读计算，不修改或发布知识条目。

请从 [中文安装与使用说明](README.zh-CN.md) 开始，也可直接浏览 [`rfkb-tools/` 源码](rfkb-tools/)。仓库不包含正式知识库、客户数据或工程图纸。
